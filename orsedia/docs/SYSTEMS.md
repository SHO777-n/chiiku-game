## 2. 戦闘(リアルタイム)

### Phase 1 仕様(これだけを実装する)

- プレイヤー: HP 20 / 移動速度 160px/s / 通常攻撃のみ
- 攻撃: Space/J で向いている方向に扇形の判定を一瞬出す(クールダウン 0.4s)
- ダメージ: 固定値(プレイヤー攻撃 3 / 敵接触 2)。`core/combat.ts` で計算し、
  将来の防御力・属性追加に耐える関数シグネチャにしておく
- 被弾後 0.8s の無敵時間(点滅)
- HP 0 でゲームオーバー → タイトルへ

### 将来(実装しない。設計メモのみ)

強攻撃・回避・防御・パリィ・スキル・魔法・属性・状態異常・コンボ・必殺技・
部位破壊・ボスギミックは ROADMAP のフェーズに従って追加。
ダメージ式は「基礎値 × 倍率 + 加算」の3層で拡張する前提。

## 3. 敵AI

### Phase 1 仕様

状態機械(`core/enemyAi.ts`、純関数):

```
patrol(巡回点を往復)
  → プレイヤーが索敵半径(120px)内 & 遮蔽なし → chase
chase(追跡、速度 110px/s)
  → 接触 → ダメージ(攻撃扱い)
  → プレイヤーが半径 220px 外 or 初期位置から 320px 超 → return
return(初期位置へ戻る) → 到着 → patrol
```

敵1種: **残響のかけら**(スライム状の小型エコービースト)。HP 6。

## 4. 会話

- Phase 1: NPCに近づき E/Enter で会話。メッセージウィンドウにページ送りで表示
- 会話データは `data/dialogues.ts`(話者名+ページ配列)。1人・一本道
- Phase 2 で選択肢・フラグ分岐・クエスト連動を追加

## 5. セーブ / ロード

- Phase 1: localStorage 1スロット。保存内容: プレイヤー位置・HP・撃破済み敵ID・保存時刻
- 保存タイミング: **Kキーで手動セーブ**(ゲームオーバー時は保存しない)。
  ※当初Sキー案だったが、WASD移動の「下」と競合するためKへ変更
- `core/save.ts` で検証。versionフィールド必須(TDD.md 4.3)

## 6. 探索・成長・経済(Phase 2 設計の要点だけ)

- レベル: 経験値テーブルはデータ駆動。VSでは Lv1→5 程度
- ショップ: 買いのみ→売り追加。通貨「リン」
- 装備: 武器/防具 各1枠から開始
- 残響再生: 指定地点で演出シーン(半透明の過去の人物+ログ)を再生し、フラグを立てる

## 7. UI

- HUD: HP(ハート/バー)。React側で EventBus 購読して表示
- ダイアログ: Phaser内のUIレイヤー
- Phase 2: インベントリ・装備・クエストログ(React側モーダル)
