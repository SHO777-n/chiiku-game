  「黙の会」が隠し続けてきたものに迫る

## 2. Vertical Slice 短編 —「眠らぬ鐘楼」(約30分)

### あらすじ

見習い聴律師リオは、師グレンの命で辺境のハルベナ村へ向かう。
村では「聞こえないはずの鐘の音が夜ごと聴こえる」という訴えと、
森のエコービースト急増が重なっていた。
リオは村人の信頼を得ながら森の奥の古代遺構「眠らぬ鐘楼」へ入り、
異変の源 ——1200年前に村を守って死んだ聴律師の未練が実体化した
「哭きの残響」—— と対峙する。

### 流れ(メインクエスト1本)

1. **導入**(2分): 師匠との会話 → 操作チュートリアル → 村へ到着
2. **村パート**(8分): 村長に門前払い → ミレの協力 → 聞き込み
   (ここでサブクエスト解放・ショップ・装備)
3. **フィールド**(7分): 躁ぎの森を探索。通常敵3種。残響の再生(情景残響)で
   1200年前の断片を目撃し、鐘楼の入口を開く手がかりを得る
4. **ダンジョン**(8分): 眠らぬ鐘楼。仕掛け1〜2個+戦闘
5. **ボス戦**(3分): 哭きの残響
6. **選択とエンディング**(2分):
   - **封じる**: 教団式の封印。村は安全になるが、彼の物語は誰にも知られない。
     ヴェイルに評価され、ミレは沈む
   - **聴き遂げる**: 残響の記憶を最後まで再生し、村人に伝えて解放する。
     村に慰霊の風習が生まれ、ミレと村長の態度が変わる。教団は警戒を強める
   - どちらでも短いエピローグ+「旅は続く」で締める(2種エンディング)

### サブクエスト(3本)

| ID | 名称 | 内容 | 報酬 |
|---|---|---|---|
| SQ1 | 迷い羊を追って | 森に逃げた羊を3匹連れ戻す(探索導線の学習) | 回復薬・お金 |
| SQ2 | 鍛冶屋の耳 | ガンドに「石の残響」の素材(鉱石)を届ける | 武器強化解放 |
| SQ3 | 聴こえる少女 | ミレの「聴こえる」原因を調べる(彼女は律血の民の血を引く——本編への伏線) | アクセサリ・好感度 |

### Phase 1 での縮小版

Phase 1は物語を最小化する:

ゲームオーバー+セーブのみ。ストーリーテキストは導入の数行に留める。
