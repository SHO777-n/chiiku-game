# GDD — 『残響のオルセディア』 Game Design Document

- 版数: 0.1(Phase 0 初稿)
- 最終更新: 2026-07-11
- ステータス: Phase 0(企画・設計)

---

## 1. ゲームコンセプト

**「土地に残された記憶の残響を聴き、忘れられた真実を世界に還すRPG」**

舞台は、1200年前の大災厄以来、強い出来事や感情が「残響(エコー)」として
土地に焼き付くようになった大陸オルセディア。
主人公は残響を読み取れる希少な素質を持つ見習い「聴律師(ちょうりつし)」。

- 探索して残響を見つけ、過去の情景を「再生」する
- 残響から得た真実を、誰に・どう伝えるかをプレイヤーが選ぶ
- その選択が人間関係・クエスト・街・国家の行方を変える

戦闘はリアルタイムアクション。残響は戦闘にも作用する
(残響が実体化した魔物「エコービースト」が主要な敵)。

## 2. ジャンル・プラットフォーム

| 項目 | 内容 |
|---|---|
| ジャンル | 2Dトップダウン・アクションRPG |
| 視点 | 見下ろし型(ピクセルアート) |
| プラットフォーム | Webブラウザ(PC優先、将来モバイル対応) |
| プレイ時間 | Vertical Slice: 約30分 / 最終目標: メイン40〜60時間 |
| 対象プレイヤー | ストーリー重視のRPGファン、探索好き |

## 3. 面白さの3本柱

1. **聴く探索** — フィールドの違和感(光、音、亡霊のような影)を手がかりに残響を発見し、
   過去の情景を目撃する。探索そのものが物語の断片収集になる。
2. **真実の扱いを選ぶ** — 知った真実を「公表する / 隠す / 特定の人物にだけ伝える / 封じる」。
   正解のない選択が世界の状態を変える。
3. **手触りの良いリアルタイム戦闘** — 少ない操作(移動・攻撃・回避)から始め、
   スキル・属性・パリィへ段階的に拡張する。

## 4. コアループ

```
探索 → 残響の発見・再生 → 手がかり/報酬の獲得
  → 戦闘・クエスト進行 → 選択(真実の扱い)
  → 世界・人間関係の変化 → 新たな探索先の開放 → (先頭へ)
```

短期ループ(数分): 移動 → 敵と戦う → アイテム/経験値 → 回復・整備
中期ループ(30分〜): クエスト受注 → ダンジョン攻略 → ボス → 選択 → 報酬と変化
長期ループ(数時間): 章進行 → 新地域 → 勢力関係の変化 → ビルド強化

## 5. 独自システム: 残響(エコー)

| 種類 | 内容 | 導入フェーズ |
|---|---|---|
| 情景残響 | 過去の出来事をその場で再生。ストーリー・謎解きの鍵 | Phase 2 |
| 感情残響 | 強い感情の痕跡。買取・調合素材、バフ付与 | Phase 3 |
| 災厄残響 | 実体化して魔物(エコービースト)になる | Phase 2(敵として) |
| 共鳴 | 複数の残響を組み合わせて隠された真実を解く | Phase 3以降 |

Phase 1では残響システム自体は実装せず、設定上の背景に留める
(敵1種を「残響のかけら」として登場させるのみ)。

## 6. 主人公

- 名前: リオ(デフォルト名、変更可能にする予定)
- 見習い聴律師。師匠グレンの命でヴェルグラント王国辺境のハルベナ村へ赴く
- 「聴こえすぎる」体質のため街に住めず、辺境育ち
- プレイヤーの選択を反映しやすいよう、口数は控えめだが選択肢で性格が出る設計

## 7. アートとサウンドの方針

- ピクセルアート(16×16〜32×32タイル)。初期はプレースホルダー図形/フリー素材で進め、
  見た目より動作を優先する
- BGM/SEはPhase 2で仕組みを導入(Web Audio / Phaser Sound)。素材はフリー音源から開始
- 「静寂と音」がテーマのため、環境音の演出を将来的に重視する

## 8. スコープ方針

- 常に「小さく設計し、小さく実装し、動作確認しながら拡張する」
- Phase 1: 最小プレイアブル(移動・会話・戦闘・セーブ)
- Phase 2: Vertical Slice(村1・フィールド1・ダンジョン1・30分の短編)
- Phase 3以降: docs/ROADMAP.md に従う
- 現フェーズに不要な機能は ROADMAP.md の「将来候補」へ記録し、実装しない

## 9. 参考作品から学ぶ点(コピーはしない)

| 作品 | 学ぶ要素 |
|---|---|
| ブレス オブ ザ ワイルド / ティアキン | 「見えるものに近づくと報酬がある」探索誘導 |
| Skyrim | 環境ストーリーテリング、サイドコンテンツの密度 |
| The Witcher 3 | 正解のない選択と後から効いてくる結果 |
| ドラゴンクエスト | 会話の温度感、村人の生活感、導線の分かりやすさ |
| FINAL FANTASY | 章構成の緩急、印象的なボス演出 |
| エルデンリング | 敵配置による緊張感、リスクとリターン |
| クロノ・トリガー | シームレス戦闘、時間(過去)を扱う物語の技法 |

## 10. リスクと対策(企画面)

| リスク | 対策 |
|---|---|
| 残響システムが「ただのムービー」になる | 再生結果が必ずクエスト・選択・報酬に接続するルールを課す |
| 選択分岐の組み合わせ爆発 | 分岐は「フラグの少数の集約変数(評判・関係値)」に畳み込む |
| スコープ膨張 | フェーズ制+TASKS.md 運用+ROADMAP「将来候補」への隔離 |
| 2D素材の制作コスト | プレースホルダー先行、面白さ検証後に差し替え |
