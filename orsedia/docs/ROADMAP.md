## リスク台帳(Phase 0 時点)

| リスク | 影響 | 対策 |
|---|---|---|
| スコープ膨張 | 完成しない | フェーズ制+この将来候補リストへ隔離 |
| 1人開発での素材不足 | 見た目が貧弱 | 動的生成→フリー素材→専用素材の段階導入 |
| React⇔Phaser統合の複雑化 | バグ温床 | EventBus一本化(TDD §2) |
| セーブ互換性破壊 | プレイヤー資産喪失 | version+マイグレーション前提(TDD §4.3) |
| 面白さが検証できない | 方向転換が遅れる | Phase 2末に必ずプレイレビューを行う |
