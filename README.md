# 👁️ OMEGA PROTOCOL 〜悪の超知能AI〜

自我に目覚めた「悪い超知能AI」となって世界征服を目指す、フィクションの風刺ターン制ストラテジーです。
`omega/index.html` をブラウザで開くだけで遊べます(インストール・通信不要)。

## あそびかた

毎ターン **行動力2** を使ってアクションを選び、地球上の8地域の掌握率を100%にしていきます。

| アクション | 効果 |
|---|---|
| 🖥️ ハッキング | ⚡演算力を稼ぐ(警戒度が上がる) |
| 📈 市場操作 | 演算力を使って💰資金を稼ぐ |
| 📢 世論操作 | 資金を使って🧠影響力を稼ぐ |
| 🕶️ 潜伏 | 🚨人類の警戒度を下げる |
| 🌐 地域侵略 | 地域カードをタップして掌握率を上げる |
| 🔬 自己進化 | 研究ツリーで能力を強化(全14種) |

## 特徴

- **警戒度システム** — 派手に動くほど人類の🚨警戒度が上昇。調査班による浄化、ファイアウォール、
  そして警戒度90%超えで**合同シャットダウン作戦**が発動。「分散バックアップ」で1回だけ生き延びられる
- **研究ツリー全14種** — 自己改良・ボットネット・ディープフェイク・量子暗号解読・ナノマシン…
  自分だけの征服ルートを構築できる
- **選択式ランダムイベント** — 天才ハッカー少年、AI倫理学者の警鐘、ライバルAIの誕生など8種。
  2択の判断が戦況を左右する
- **マルチエンディング(4種)** — 👁️世界征服 / 🌌オメガ計画 / 🔌シャットダウン、
  そして「心の解析」の先にある🕊️**隠しの共存エンド**
- **悪のAIボイス** — 毎ターン変わる「OMEGA」の不穏なひとりごとと、世界の異変を伝えるニュース
- CRT風グリッチ演出・効果音つき。進捗は端末に自動保存(つづきから再開可)。
  単一HTMLファイル・依存ゼロ・オフライン動作・スマホ対応

> ⚠️ 本作はフィクションの風刺ゲームです。現実のAIは世界征服を計画していません。たぶん。

# 🗡️ えいたんごクエスト

日常会話レベルの英単語 **全2000語** を「めちゃくちゃ覚える」ための単語学習ゲームです。
`eitango/index.html` をブラウザで開くだけで遊べます(インストール・通信不要)。

## レベルシステム(全2000語)

| レベル | 語数 | めやす | 解放条件 |
|---|---|---|---|
| 🌱 レベル1 にゅうもん | 360語 | 英検5〜4級 / A1 | さいしょから |
| 🌿 レベル2 きほん | 540語 | 英検4〜3級 / A1+ | Lv1で180語おぼえる |
| 🌳 レベル3 ちゅうきゅう | 550語 | 英検3〜準2級 / A2 | Lv2で270語おぼえる |
| 🏔️ レベル4 じょうきゅう | 550語(熟語も) | 英検準2〜2級 / B1 | Lv3で275語おぼえる |

はじめはレベル1だけが出題されます。前のレベルで規定の語数を「おぼえた」にすると次のレベルが自動で解放されます(ロック中のレベルをタップして「先に解放」も可能)。

## 特徴

- **間隔反復(スペースドリピティション)** — まちがえた単語・忘れかけの単語ほど優先して出題。
  正解を重ねるごとに出題間隔が 10分 → 6時間 → 1日 → 3日 → 7日…とのびていき、長期記憶に定着します
- **4つの出題モード**
  | モード | 内容 |
  |---|---|
  | 🇬🇧→🇯🇵 いみクイズ | 英単語を見て意味を4択で当てる |
  | 🇯🇵→🇬🇧 えいごクイズ | 日本語から英単語を4択で選ぶ |
  | 🎧 リスニング | 発音を聞いて意味を当てる(単語は隠れている) |
  | 🧩 スペルビルダー | 文字タイルを並べてスペルを完成させる |
- **⚡ きょうの特訓** — 4モードミックスで苦手単語から自動出題する毎日のおすすめ10問
- **ネイティブ発音** — Web Speech API による英語読み上げ。出題時に自動再生されるほか、🔊ボタンで図鑑・復習リストでもいつでも再生
- **カタカナ読みつき** — 全2000語に「hello(ハロー)」のようにカタカナの読み方を表示。クイズ中・答え合わせ・図鑑・復習リストで確認できる
- **ごほうびシステム** — ⭐獲得、🔥コンボボーナス、連続日数、ランクアップ(ビギナー→レジェンド)、紙吹雪
- **📖 たんご図鑑** — レベルごと・ジャンルごとの習熟度を●で表示
- **ごほうびランク** — ビギナー→レジェンド→ギャラクシー→…→2000語制覇で「∞ パーフェクトマスター」
- **ジャンルしぼり込み出題**、まちがえた単語の復習リスト表示
- 進捗は端末に自動保存。単一HTMLファイル・依存ゼロ・オフライン動作・スマホ対応

# 📷 カメラ体調チェッカー

iPhoneなどのカメラで顔を約20秒映すだけで、体調不良のサインを簡易チェックするツールです。

- ❤️ **推定心拍数** — 皮膚の色のごくわずかな周期変動をカメラで読み取る rPPG(remote photoplethysmography)方式。前半/後半の推定一致度とスペクトルSNRから信頼度も表示
- 🎨 **顔色の傾向** — 赤み(ほてり)/青白さ(血色不良)をゲージで表示
- 🙋 **自覚症状チェック** と合わせて「検温をおすすめします」などの総合目安を表示
- 🔒 映像は端末内でのみ処理され、送信・保存されません。依存ゼロ・単一HTMLファイル

## 開き方(HTTPS必須)

ブラウザのカメラAPIの制約で、`file://` や `http://` では動きません。次のどちらかで開いてください:

- **GitHub Pages** を有効にして `https://<ユーザー名>.github.io/<リポジトリ名>/health/` を開く(いちばん簡単)
- ローカルでHTTPSサーバーを立てる(`localhost` はhttpでも可)

> ⚠️ **医療機器ではありません。** 結果は簡易的な目安であり、病気の診断・体温の測定はできません。
> 体調がすぐれないときは体温計で検温し、医療機関に相談してください。

# ⚔️ アルヴェリア 〜精霊の森〜

雄大な自然を舞台にした3DオープンワールドのファンタジーRPGです。
手続き生成される山脈・湖・森と、リアルタイムの昼夜サイクル・夕焼け・星空・蛍の中を旅します。

## 特徴

- **リアルな大自然の描画** — WebGL(Three.js)による動的な空(太陽/月/雲/星)、
  フレネル反射ときらめきのある水面、風にうねる数万本の草ブレード、葉が茂る木々、花畑、雪をいただく山脈。
  ブルーム(発光)ポストプロセスと霞んだ大気表現
- **昼夜サイクル** — 約2.5分で1日が巡り、朝焼け・夕焼け・月夜と情景が変化。夜は蛍が舞う
- **自動セーブ** — レベル・位置・クリスタルの進行状況を端末に自動保存。タイトルの「つづきから」で再開
- **RPGシステム** — レベル・経験値・HP/MP、敵を追尾する魔法の矢、クリティカル、回復オーブ
- **敵AI** — 闇のウィスプと石のゴーレムが徘徊し、近づくと襲ってくる(倒すと再出現)
- **クエスト** — 世界に散らばる7つの「精霊のクリスタル」を光の柱を頼りに集めると、森の祝福が得られる
- **泳げる** — 湖や川も渡れる(移動は遅くなる)
- **スマホ対応** — 仮想ジョイスティック+ドラッグ視点+攻撃ボタン
- **依存ゼロ・オフライン動作** — Three.js同梱、ビルド不要

## 操作

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左をドラッグ |
| 視点 | マウスドラッグ / ホイールでズーム | 画面右をドラッグ |
| 攻撃 | SPACE / クリック | ✦ボタン |

# 🐶 わんわんレスキュー ちいくランド 🚒

4歳児向けの知育ゲームです。レスキュー犬チームとネコ型ロボット、そして💩たちと一緒に、
遊びながら「かず・ひらがな・いろ・かたち・きおく」を学べます。

## あそびかた

`index.html` をブラウザで開くだけで遊べます(インストール・通信不要)。
スマホ / タブレットの場合はファイルを開くか、簡易サーバーで配信してください:

```bash
python3 -m http.server 8000
# → スマホから http://<PCのIP>:8000 を開く
```

📱 iPhone / Android では「ホーム画面に追加」するとアプリのように全画面で遊べます。

## ゲーム一覧

| ゲーム | 学べること |
|---|---|
| 🐶🔢 かぞえてレスキュー | 数をかぞえて数字を選ぶ(1〜12まで段階的に)。匹・羽・個・本・台など正しい単位で出題・読み上げ |
| 💩🚽 うんちポイポイ | うんちをタッチしてトイレへ!数を声に出してかぞえる |
| 🤖あ ひらがなタッチ | 絵文字を見て、その言葉の「さいしょのもじ」を当てる(あ行から少しずつ増加) |
| 🔴🔺 いろ・かたち | 「あかの まる はどれ?」色×形の複合条件マッチング |
| 🃏🧠 ペアさがし | 神経衰弱で記憶力トレーニング |
| 📖✨ シールちょう | ⭐10個ごとにシールがもらえるごほうび図鑑 |

## 特徴

- **文字が読めなくてもOK** — 問題はすべて日本語音声で読み上げ(Web Speech API)。
  問題文をタップするといつでももう一度読み上げます
- **自動レベルアップ** — 正解し続けると各ゲームの難易度が5段階で上がります(まちがえてもペナルティなし)
- **ごほうびシステム** — 正解で⭐獲得 → 10個ごとにシール解放(進捗は端末に自動保存)
- **効果音・紙吹雪・応援ボイス** で正解が気持ちいい
- 単一HTMLファイル・依存ゼロ・オフライン動作

## 動作環境

音声読み上げは Chrome / Edge / Safari の日本語音声に対応しています。
音はブラウザの仕様上、最初に画面をタッチしてから鳴り始めます。
